# Rizky Noufal Hidayat - Portfolio Website

Personal portfolio website for Rizky Noufal Hidayat (Backend Engineer specializing in Golang, REST APIs, and Clean Architecture).

## Tech Stack

- **Core**: Vanilla HTML5, Semantic Markup
- **Styling**: Vanilla CSS3 (Custom Design Tokens, Light Theme, CSS Grid & Flexbox)
- **Logic**: Vanilla JavaScript (ES6+, zero external libraries)
- **Assets**: Standalone PDF CV and SVG vector icons

## Running Locally

Because this project is built with pure Vanilla web technologies, no build step or package manager is required:

1. Double-click `index.html` to open it directly in any modern web browser.
2. Alternatively, serve via any lightweight static server:
   - VS Code extension: **Live Server**
   - Python: `python -m http.server 3000`
   - Node: `npx serve .`
